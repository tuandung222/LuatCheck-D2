Scope: official, publicly accessible regulations of Trường Đại học Bách khoa – ĐHQG-HCM (HCMUT) that students consult for academic-affairs rules. Every included document is 25 pages or fewer, has a usable text layer, and is hosted on `hcmut.edu.vn`. Corpus: `data/corpus/hcmut_academic_v1.json` (10 documents, 143 sections).

Retrieval: 2026-10-22 20:04–20:08 UTC (times recorded per file in `download_log.tsv`). Collection script: `extract_hcmut_corpus.py`. Metadata and computed checks: `manifest.json`.

## Gaps and caveats

1. **Core rules are not in the corpus.** The main 2021 undergraduate regulation (2933) is image-only. Its warning (cảnh báo học vụ), dismissal (buộc thôi học), graduation, leave (bảo lưu) and transfer (chuyển ngành) rules are therefore not extracted. The amendments only cover changed clauses. The 10 documents answer some tuition, advisor, conduct, teaching and credit-structure questions, but not the core undergraduate rules.
2. **Less relevant documents included to reach the count.** NOIQUY1924 (campus conduct), UNGXU3408 (code of conduct) and VINHDANH658 (awards) are student-facing but not academic-affairs rules. CTDT1862 concerns programme design. Replace them if the benchmark needs only academic-credit rules.
3. **Unverified metadata.** The printed number and date are blank in all PDFs. Number and date come from the listing and are not checked against a signed copy.
4. **Date conflicts.** 2749 cites Decision 1260 as dated 16/03/2026, but the listing says 15/03/2026. 1862 dates the base 3538 as 11/09/2025, but the listing says 10/09/2025. 2749's listing title is misspelt "học vũ".
5. **Versions and supersession not verified.** Whether any document is superseded by a later consolidated text (the "Phiên bản hợp nhất" the hcmut site refers to) was not found in the listing. The 2015/2017 Quy chế công tác sinh viên (925/QĐ-ĐHBK-CTCT-SV) is the only ĐRL-related text and is image-only, so the training-score (điểm rèn luyện) rule is not in the corpus.
6. **Amendment sections are clause-level fragments.** For amendments, sections are the decision articles, split further at quoted clause headings (`Dieu_1_S3_1` means clause 3.1 of the amended base). CTDT1862 Điều 1 (about 19.5k characters) has no clause headings the splitter recognises, so it stays one section.

## Extraction and checks

Method: `pypdf` text per page. Only these changes are applied: Unicode NFC, collapsed whitespace, removal of bare page numbers at page edges, removal of lines repeated at page edges on at least 3 pages (with at least one 3-letter word, so ellipses and numbering stay), and Preamble citations ("Căn cứ ...") before the first heading are excluded from records. The blank "Số/ngày" template lines are kept as printed.

Section ids: `Dieu_N` = article N of the operative text. `QD_Dieu_N` = article of the decision wrapper that precedes an attached annex (standalone regulations). `PhuLuc_N` = appendix N. `_S<a>_<b>` = clause split of an oversized section. A duplicate id gets `_2`, `_3`.

Record fields: the required fields plus `metadata_verification` (flags the blank printed number/date).

Sanity checks (run by `extract_hcmut_corpus.py --check`):
- 10 included documents, 143 records, 143 unique `doc_id`, no empty content.
- Every included document is ≤25 pages (max 21).
- SHA-256 of each file recomputed and equal to `manifest.json`.
- Each record's content is a substring (whitespace-normalised) of the cleaned extracted text, and each content line appears in the raw text.
- Excluded documents have no records.
- Result: all checks passed.

Re-run from the repository root:
```
.venv/bin/python -I docs/materials/hcmut-sources/extract_hcmut_corpus.py          # rebuild corpus and manifest
.venv/bin/python -I docs/materials/hcmut-sources/extract_hcmut_corpus.py --check  # verify
```
Downloads (done with `curl -L -A "Mozilla/5.0"` on the `source_url` of each manifest entry) are not performed by the script.
