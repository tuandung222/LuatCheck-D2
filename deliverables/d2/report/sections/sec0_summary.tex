\fbox{\parbox{\dimexpr\textwidth-2\fboxsep-2\fboxrule\relax}{\small
\textbf{Summary.} LuatCheck answers a question only from a document collection, cites the sections it used, checks each citation against the source text in code, and refuses or asks for clarification when the sources do not answer. It is a single bounded agent whose controller is a 4-billion-parameter model that runs locally on a laptop (a lighter 2B option is also supported). It uses read-only search and read tools, keyword retrieval with a neural reranker, a deterministic rule-based citation verifier (a Python heuristic gate, not a neural model or second agent) with bounded repair, and input guardrails.\par\smallskip
\textbf{Evaluated:} two benchmarks of 50 Vietnamese questions each (HCMUT regulations, labour law), three configurations (no verifier, verifier, verifier and reranker), three random seeds, plus two diagnostic baselines; 1{,}090 recorded trials per controller. Strict success means appropriate behaviour, a correct and complete answer, and every claim supported by the sources. An LLM judges it (lower bound over all trials); on a blind 60-item human audit (30 per benchmark), judge--human agreement on strict success is 96.7\% ($\kappa=0.93$) on HCMUT regulations and 90.0\% ($\kappa=0.80$) on labour law.\par\smallskip
\textbf{Result:} with the 4B controller, the full system reaches 60.7\% (HCMUT regulations) and 56.7\% (labour law) strict success, compared with 28.7\% and 28.0\% with the lighter 2B controller (+32.0 and +28.7 percentage points). In the ablation, neither the verifier nor the reranker raised strict success on these benchmarks, as repeated verifier rejections end as refusals; we retain both for auditable citations and will test on a harder unseen benchmark in Week 45.}}
