\hdr{Scope and users.} The proposal (Application Track) targeted employees and HR staff asking labour-law questions. For this report we added a second corpus, the academic-affairs regulations of HCMUT used by students and advisers, to test whether the same code serves another domain. Wording, tool names and document-id rules are configuration per domain.

We claim only what was evaluated: ten HCMUT documents and ten labour-law documents (the 2019 Labour Code with two laws, six decrees and one circular of 2020--2025), snapshot of 22 October 2026, later amendments unchecked. LuatCheck is not legal advice and has not been tried by real users.

Intended scenarios: a student looks up a rule and opens the cited section; an HR officer checks a labour-law answer against the cited article; a careless or hostile user pastes a document with injected instructions, and the system must keep its tool boundary and refuse or clarify.

\hdr{Engineering refinements during D2.} An early 2B prototype reached only 12--19\% strict success because (i) the model's short search queries dropped key terms from the user's question (first-search top-3 recall 0.71 and 0.62 vs 0.95 and 0.98 using the raw question), (ii) the controller exited via \texttt{clarify} whenever evidence was missing from a truncated snippet (37\% and 30\% of answerable tasks), (iii) a verifier rejection message phrased as a warning caused the model to refuse in 56\% and 53\% of cases instead of repairing, and (iv) the citation verifier rejected valid quotes containing ellipses (\texttt{...}) or PDF line wraps.

In the D2 system, the first search automatically anchors on the user's original question plus the model's query (\texttt{top\_k=5}), \texttt{search} is required before \texttt{answer} with explicit clarify/refuse rules and reasoning capped at 800 characters, and the citation verifier returns a neutral tool report with the closest source passage while supporting elided quotes and sentence-local number checks. We evaluate both the 4B controller (default) and the 2B controller (lighter option).
