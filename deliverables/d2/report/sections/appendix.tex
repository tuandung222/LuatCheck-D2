\section*{Appendix: Generated Result Tables}
The tables below are generated automatically from the recorded runs; a script only replaces internal names by plain labels, and every number is unchanged. They are the source of the numbers in Section~\ref{sec:eval}. The run, commit and checksum of each table are stored in machine-readable headers of the table files in the repository. \textbf{A.} Comparison of the initial system (2B controller) with the current system with the 2B and the 4B controller: strict success with paired differences, then behaviour match, Recall@5, answer rate and execution-error rate. \textbf{B.} Result tables of the two runs of the current system with the 4B controller, one per benchmark.\par\medskip
